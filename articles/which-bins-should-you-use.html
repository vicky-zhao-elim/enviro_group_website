Which bins should you use?

By Firstname Lastname | Weekday Date Month Year

Recently we have noticed an increase of the wrong rubbish in the wrong bins. This makes it harder for us to use the bins properly, so we would appreciate it if you followed the rules for each bin.

Landfill is the general bin where students can put any item in it. If you are not sure what bin to use, please use this one. Compost is for organic foods, usually fruits. Soft plastics is for plastics which can be scrunched, such as plastic bags. Other plastics is for other things. For more information, see our other article on this topic.
